# Политика компании UltraGram

## 1. Кто мы
UltraGram — независимая платформа общения. Мы не являемся клиентом или копией других мессенджеров. Это собственный продукт, собственная экосистема, собственные серверы.

## 2. Главное правило
**Никогда не раскрывать пароли, токены, секреты и личные данные пользователей.** Ни в логах, ни в отчётах, ни в GitHub, ни в чатах — ни при каких обстоятельствах.

## 3. Пользователи и данные
- Каждый пользователь имеет право на приватность.
- Пароли хранятся только в зашифрованном виде (bcrypt).
- Токены авторизации не показываются и не публикуются.
- Личные сообщения, файлы и медиа доступны только участникам переписки.
- Администраторы не читают чужие сообщения без юридического основания.
- Удаление аккаунта удаляет все личные данные пользователя.

## 4. Безопасность
- Все соединения в production идут через HTTPS/WSS.
- HTTP разрешён только для локальной разработки и эмулятора.
- Секреты (JWT, пароли, ключи) хранятся только в переменных окружения, никогда в коде.
- База данных не выставляется наружу.
- Резервные копии создаются регулярно.
- Перед любой опасной миграцией делается бэкап.

## 5. Администраторы
- Администраторы проверяются на сервере, а не только в интерфейсе.
- Роли: ADMIN, Verified UltraGram.
- Пароли администраторов не сохраняются в репозитории.
- Сброс пароля выполняется только с согласия владельца аккаунта.
- Новый пароль показывается один раз и нигде не хранится.

## 6. Разработка
- Не ломаем существующие аккаунты и переписки.
- Не удаляем базу данных без бэкапа.
- Не используем фиктивные данные вместо настоящих.
- Не заявляем о готовности функции без реального тестирования.
- Каждое изменение сохраняется в Git.
- Версии обновляются по порядку: 1.0.0.F1, F2, F3, F4...

## 7. Релизы
- Каждый релиз содержит APK и/или Windows Setup.
- Каждый файл имеет SHA-256 для проверки.
- Прямые ссылки на скачивание публикуются в отчёте.
- Не публикуем нерабочие APK без предупреждения.

## 8. Подключение к серверу
- Адрес сервера задаётся разработчиком через конфигурацию сборки.
- Пользователь не видит и не меняет адрес backend.
- Debug: локальные адреса (10.0.2.2, LAN IP).
- Release: только HTTPS, без исключений.
- Если сервер недоступен — показываем понятное сообщение, а не технические детали.

## 9. Звонки и медиа
- Аудио и видео звонки работают между Windows и Android.
- Используется WebRTC + WebSocket signaling + STUN/TURN.
- Потоки передаются напрямую, не хранятся на сервере.
- Разрешения камеры и микрофона запрашиваются у пользователя.

## 10. Валюта и подарки
- Огньки 🔥 — внутренняя валюта UltraGram.
- Баланс одинаковый на всех устройствах.
- Все операции проверяются на сервере, клиент не может сам начислять валюту.
- Подарки и NFT имеют учёт владения на сервере.

## 11. Уведомления
- Android: Firebase Cloud Messaging.
- Windows: системные уведомления.
- Пользователь может отключать уведомления для отдельных чатов.

## 12. Обновления
- Проверка новой версии при запуске.
- Сохранение пользовательских данных при обновлении.
- Android: скачивание APK или переход к официальному релизу.
- Windows: загрузка и установка обновления.

## 13. Итог
UltraGram — собственная платформа. Мы не копируем чужие бренды и не создаём клиенты для других сервисов. Все данные пользователей защищены. Пароли никогда не раскрываются.

**ULTRAGRAM — OWN PLATFORM. OWN ECOSYSTEM. OWN FUTURE.**
