# Cookie Policy — UltraGram

**Company:** NoInfoTeam
**Product:** UltraGram
**Last updated:** 27 November 2026

## Desktop (Electron)
UltraGram Desktop does not use browser cookies. Session data is stored locally in encrypted form.

## Web client
The web client may use:
- Session tokens (stored in memory/localStorage).
- No third-party tracking cookies.

## Mobile (Android)
UltraGram Android does not use cookies. Session tokens are stored in SharedPreferences.

## Summary
UltraGram does not use advertising or tracking cookies. Only essential session data is stored for authentication purposes.
