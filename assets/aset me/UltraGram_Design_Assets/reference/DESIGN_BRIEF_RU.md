# Дизайн UltraGram

- Самостоятельный бренд UltraGram; не копировать логотипы и фирменные элементы Telegram.
- Современный интерфейс мессенджера: список чатов слева, активный диалог по центру, профиль/информация справа.
- Тёмная основа, фиолетово-синие акценты, аккуратные скругления, понятная типографика.
- Адаптивность для узких экранов.
- Все кнопки должны выполнять реальные действия.
